# 切圖磚說明書
<!-- site:content -->

`tilecut` 是把一張自繪插畫變成「地圖上蓋著底圖的透明疊圖」的工具。切好之後不是自動出現在地圖上——還要到後台「編輯專案描述」把這個圖層勾起來，那張地圖才看得到。

## 這支工具在做什麼

一張插畫如果直接整張蓋在地圖上，放大時要整張重新下載、也會糊掉；手繪稿常常是幾十 MB。這支工具把圖切成一格一格 256×256 的「圖磚」，瀏覽器只抓看得到的那幾格，放大時再抓細一級的圖磚，跟 Google 地圖的底圖是同一套做法。

切好的圖磚只屬於「這張地圖」，不是全站共用的底圖。

## 步驟一：圖層名稱與來源圖片

**圖層 id** 只能用小寫英數字、底線、連字號，它同時是伺服器上的資料夾名稱。如果跟全站共用的圖層剛好同名，這張地圖會優先用自己切的這一份。

**圖片檔案**：支援 PNG／WebP／JPEG／SVG，可以一次選很多張。想讓沒畫到的地方透出下面的底圖，檔案本身要有透明背景（例如去背過的 PNG）——JPEG 沒有透明通道，整張都會蓋住下面。

**疊很多張時**：清單由上到下就是由上層蓋到下層。切磚時整疊會壓成一張：上層蓋住下層，上層透明的地方透出下層，全部都沒畫到的地方就透出地圖本身的底圖。每一張都可以個別隱藏、個別調不透明度、個別對位——適合「線稿一張、上色一張」這種分層畫法，或是同一張插畫想個別調整某個角落的不透明度。

## 步驟二：在地圖上對位

這一區調的永遠是清單裡「目前選取的那一張」。

- 中央的圓形把手：拖著整張移動位置。
- 兩個角落的方塊把手：拖曳縮放大小（預設鎖定長寬比，插畫不會被拉變形）。
- 「用目前視野」：直接把這張圖套進地圖現在看到的範圍，比手動拖曳快，適合先抓大概位置再微調。
- 下方四個數字（北／南／西／東）是同一件事的精確版，手動輸入或微調都可以。

## 步驟三：輸出設定

**縮放層級（zoom）**：這是「圖磚要切到多細」的意思，跟地圖放大縮小的等級是同一個概念——數字愈大，圖磚愈細、檔案愈多。工具會自動抓一個合理範圍（依圖片實際解析度決定切到多細算合理，即「原生」那一級），通常不用手動改。如果手動調，超過原生那一級再切只是把同樣的像素放大，白佔硬碟空間；使用者放大超過最大層級時，地圖會自動把最後一級的圖磚拉伸撐大，圖層不會憑空消失，只是看起來比較模糊。

**Pane（圖層疊放順序）**：決定這張插畫疊在地圖的哪一層——蓋在道路上面還是壓在路面下面，跟其他圖層的前後關係。

**不透明度**：整張插畫的透明度，跟每一張個別小圖的不透明度是分開的兩件事——這裡調的是「壓平之後整組」再套一層透明度。

**出處**：顯示在地圖角落的圖資來源文字，例如作者、授權方式。

## 保持向量（純 SVG 專用）

清單裡**剛好只有一張、而且是 SVG** 時，輸出設定上方會多出「保持向量」這個選項。勾起來之後，縮放層級、保留原稿這些欄位會整組隱藏——不是不能用，是這個模式下用不到：SVG 本身就是圖層本體，不用切磚也不用另外決定要不要留底稿。

原理：一般模式是把圖片壓平、切成一格一格的圖磚檔案；保持向量模式完全跳過這一步，直接把這張 SVG 原封不動當成一整張疊圖蓋上地圖。放大到多細都不會糊——SVG 本來就是無限縮放的格式，圖磚反而是把它點陣化，放大到極限一樣會糊。檔案通常也比切成圖磚小得多，尤其是線稿這種色塊少的插畫。

只要清單裡加到第二張、或是這張不是 SVG，這個選項就會自動收起來，切磚照舊用一般模式，不用手動切換。

## 保留原稿

預設會把上傳的原始圖檔（切磚前那一張）一起存到伺服器上，只有這張地圖的管理者拿得到，之後可以回來這個工具用同一個 id 載回、重新對位、重新切一次——不用重畫、也不用記得上次是怎麼擺的。

如果不想要伺服器留底稿（例如原始檔案很大、或不打算之後再調整），把「保留原稿」取消勾選即可，這樣就只留圖磚——連上一次留的原稿也會一併刪掉，之後只能重新上傳整張圖從頭切。

留了多少原稿、佔了多少空間，在後台的圖層清單裡看得到——每一層旁邊會標出目前佔用的容量，只有真的留著原稿的層才會顯示。匯出圖層 ZIP 時也能選「含原稿」，把原稿一起打包帶走，換到別的伺服器上照樣能用這支工具載回來重新編輯。

## 沒留底稿時：從圖磚重建

如果之前取消勾選過「保留原稿」，用同一個圖層 id 再回來這支工具時，會看到「從圖磚重建」的提示，而不是正常的「已載入上次的原稿」。

這是最後的補救辦法：把已經切在伺服器上的圖磚一格一格拼回一張圖，當成全新的來源圖片，重新對位、重新切一次。按下「從圖磚重建」之後需要花一點時間逐格下載，圖磚愈多等愈久。

**拼回來的圖是壓平過的**——如果原本這個圖層是好幾張圖疊出來的（線稿一張、上色一張那種疊法），疊層資訊已經回不去了，重建出來只會是疊好之後的單一張圖。位置和範圍是照圖磚本身的網格精準對齊，通常不需要再調整，但畫面內容本身沒辦法拆回原本那幾張。

重建完成後，記得保持「保留原稿」勾選再按一次「開始切」——這樣往後就會留底稿，不會再需要用到這個補救辦法。

## 切完之後

工具本身只負責把圖磚放到正確的資料夾，**不會**自動讓地圖顯示它。要讓某張地圖用上這個圖層，去後台該地圖的「編輯專案描述」，在圖層清單裡把它勾起來、排到想要的疊放順序，存檔後才會出現。
